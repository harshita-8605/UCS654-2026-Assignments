TOPSIS Package

This package implements the Technique for Order Preference by Similarity to Ideal Solution (TOPSIS).

Installation:
pip install Topsis-Harshita-102317003

Usage:
topsis-harshita-102317003 <input_file> <weights> <impacts> <output_file>

Example:
topsis-harshita-102317003 data.csv "1,1,1,1,1" "+,+,+,+,+" result.csv

Input file must contain numeric values from second column onwards.
Weights and impacts must be comma separated.
